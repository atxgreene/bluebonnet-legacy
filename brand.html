Brand System

Bluebonnet Legacy

A compact production guide for the public brand, built from the asset pack and tightened for web use.

Architecture

Use Bluebonnet Legacy as the public brand.

Bluebonnet Capital and Bluebonnet Holdings remain reserved names unless they become formal entities or service lines.

Color Tokens

Warm, sober, operator-first.

Heritage Navy#24354D
Bluebonnet Ink#2E4666
Leaf Green#566F4F
Warm Ivory#F4F1EA
Stone Gray#B8B2A8
Antique Gold#C8A65A

Typography

Georgia for authority. System sans for clarity.

Use Georgia for major display headings and system sans-serif for body copy, navigation, labels, and operational content.

Spacing

8px radius. 16px rhythm. No decorative noise.

Cards and panels use restrained corners, visible borders, and generous section padding. The interface should feel executive, not ornamental.

Framework Language

Use these eight terms consistently.

Financial Clarity Operational Structure Incentive Alignment Leadership Rhythm Process Engineering Technology Leverage Reporting Architecture Capital Efficiency

Logo Usage

Use the simplified SVG mark for small contexts.

The raster crops remain archived in `assets/asset-pack/` as source references. Use the SVG mark for favicon, social avatar, small UI placement, and future print vector work.
